# AllerCat

AllerCat is a Progressive Web App (PWA) for tracking daily allergy immunotherapy. A customizable cat companion keeps you company, with selectable cat breeds. Log multiple pills per day, and generate reports to share with your doctor.

## Features

- Daily allergy immunotherapy tracking
- Customizable cat companion breeds
- Multi-pill logging
- Doctor reports
- Installable and usable offline as a PWA

## Development

```bash
npm install
npm run dev
```
